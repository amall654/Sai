# Sai project working rules

- Work only on `ux-amal`. Never switch to `main` or another branch unless the user explicitly requests it.

- This repository is the only active project. Edit the website in interface-prototype/dist.
- Read current files and git status/diff before editing. Never restore older files over current work without comparing and merging.
- archive contains historical reference material only, not another working website.
- Preserve separate home, opportunities, learning, experiences, login, and profile screens.
- Home uses the approved automatic card: "خطوتك اليوم", one centered sentence, no wheel, no card signature or extra subtitle. Preserve reduced-motion support and mobile layout.
- Preserve the English workspace's student profile preview and local Cairo heading font.
- Do not reintroduce removed university affiliation/disclaimer text or the "نموذج واجهة تجريبي" badge unless requested.
- Preserve existing functionality outside the requested change; account and data services remain unconnected until explicitly implemented.
- Check JavaScript syntax, routing behavior when changed, and git diff before committing. Commit coherent approved changes; do not force-push.
