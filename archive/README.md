# أرشيف المشروع

المجلد النشط الوحيد للواجهة هو ../interface-prototype/dist.

arabic-workspace-2026-10-01.zip نسخة كاملة من مجلد سعي العربي السابق، تشمل الوثائق وسكربتات إنشائها وصور المراجعة والنسخ القديمة وسجل Git المحلي. تحققت مطابقة الملفات ببصمات SHA-256 المسجلة في arabic-workspace-manifest.json قبل حذف الأصل.

هذا أرشيف مرجعي، وليس نسخة عمل. لا تستخرج الواجهة القديمة فوق الواجهة المعتمدة. ملفات Word الميسرة للتحرير موجودة داخل ../doc، في مجلد كل وثيقة بجانب نسختي PDF وMarkdown. سكربتات الإنشاء القديمة قد تحتوي مسارات قديمة؛ راجعها قبل تشغيلها.

الواجهة الإنجليزية الأصلية محفوظة في commit 037a44b، وتعديلات الواجهة العربية محفوظة داخل سجل Git في الأرشيف عند commit 1664edf.

قد تصف الملفات داخل الأرشيف الأندية والملف الموسع والإنجازات والشهادات كأهداف أو متطلبات. هذه تصورات تاريخية مؤجلة بقرار 4 أكتوبر 2026، وليست نطاق التنفيذ الحالي. اعتمد النسخ المحدّثة داخل doc؛ لا يُعاد تحرير الأرشيف المضغوط أو تغيير بصماته.

قرار 5 أكتوبر 2026: النطاق النشط محصور في كلية الهندسة وعلوم الحاسب. أي تغطية لكليات أخرى داخل الأرشيف تصور سابق مؤجل، مثل الأندية والملف العام؛ راجع doc/RELEASE-1.md للنطاق الحالي. لا تعاد كتابة النسخ التاريخية.
