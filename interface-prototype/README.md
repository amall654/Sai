# نموذج واجهات سعي

نموذج بصري مستقل لصفحة الرئيسية وتسجيل الدخول، وليس التطبيق النهائي أو نظام حسابات. لا يجمع كلمات المرور، ولا يتصل بـFirebase. جميع بطاقات الفرص والجهات والتجارب أمثلة موضحة داخل الواجهة.

## ابدئي بالتعديل

1. افتحي المجلد في VS Code.
2. افتحي `dist/index.html` في المتصفح؛ يمكن فتحه بالنقر مرتين أيضًا دون تثبيت حزم.
3. غيري قيمة صغيرة واحفظي، ثم حدّثي المتصفح لتري النتيجة.

## أين أغيّر ماذا؟

- الألوان والخط وحجم الزوايا: `dist/theme.css`. مثلًا غيّري `--green` إلى لون آخر. احتفظي بعلامة `#` والفاصلة المنقوطة.
- نصوص البطاقات وإضافة أو حذف بطاقة: `dist/content.js`. انسخي عنصرًا كاملًا داخل القائمة، وأعطيه `id` مختلفًا. لا تحذفي الفواصل بين العناصر. النصوص بين علامتي اقتباس.
- عناوين الأقسام والعبارة الرئيسية: `dist/index.html`. غيّري النص الموجود بين الوسوم فقط في البداية.
- ترتيب الأقسام: انقلي عنصر `section` كاملًا داخل HTML مع وسم إغلاقه. احتفظي بـ`id` لأن التنقل يعتمد عليه.
- المسافات وأحجام البطاقات والجوال: `dist/styles.css`. الأجزاء داخل `@media` تتحكم بعرض الشاشات الصغيرة.
- التفاعل والحفظ المؤقت والتنقل والنوافذ: `dist/app.js`. اتركيه في أول تعديلاتك حتى تتعرفي على JavaScript.

## تجربة أولى سهلة

غيّري عنوان فرصة في content.js، ثم لون `--green` في theme.css، واحفظي الملفين وحدّثي الصفحة. إذا لم يعجبك التغيير، استخدمي التراجع في المحرر قبل إغلاقه. راجعي الفروق في Git قبل حفظ نسخة جديدة.

## ما الذي يعمل؟

التنقل بين شاشات مستقلة للرئيسية والفرص وجهات التعلم وتجارب الطلاب والدخول، مع دعم الرجوع والتقدم في المتصفح والروابط المباشرة، تصفية أمثلة الفرص بالاهتمام، فتح التفاصيل، عرض حالة المحفوظات دون تعديل، وإظهار كلمة المرور التوضيحية. النوافذ تدعم الإغلاق وEscape. الجوال له شريط سفلي والكمبيوتر شريط علوي.

الحفظ والتعديل والإضافة والحذف ورفع الملفات معطلة في المعاينة. لا يوجد تسجيل حقيقي أو إرسال بريد أو تسجيل صوتي أو نشر تجربة. لا توجد روابط تقديم أو مواعيد مصطنعة تقدم كفرص حقيقية.

## لماذا ملفات بسيطة؟

هذا مرجع تصميم قليل التعقيد يمكنك تعديله دون إعداد أدوات بناء. لا يستبدل اختيار React وFirebase للتطبيق الفعلي؛ يمكن تحويل أقسامه إلى مكونات React عند البدء بالربط. لا تنسخي كود نموذج الدخول على أنه مصادقة حقيقية.

## معاينة على خادم محلي اختياري

إذا كان Python مثبتًا، افتحي الطرفية داخل هذا المجلد:

```text
python -m http.server 5173 --directory dist --bind 127.0.0.1
```

ثم افتحي http://127.0.0.1:5173 . لإيقاف المعاينة اضغطي Ctrl+C.


## الشاشات المستقلة

تعرض الرئيسية المقدمة فقط. تفتح روابط الشريط العلوي وشريط الجوال شاشة القسم المختار وتخفي باقي الشاشات؛ لا تظهر الأقسام عند النزول في الرئيسية. فلاتر الاهتمامات داخل شاشة الفرص، ودعوة المشاركة داخل شاشة تجارب الطلاب. يمكن فتح الشاشة مباشرة باستخدام `#opportunities` أو `#learning` أو `#experiences` بعد عنوان الصفحة.


## معاينة ملف الطالب

زر «معاينة حساب طالب» يعرض الرئيسية كما هي ويضيف رابط «أحمد · ملفي» أعلى الواجهة. ملف الطالب شاشة مستقلة بعنوان `#profile` وبياناتها ثابتة وتوضيحية. يمكن العودة لوضع الزائر من الشريط التوضيحي. لا توجد مصادقة أو كتابة لقاعدة بيانات أو رفع ملفات، وأزرار تعديل الملف وإضافة الإنجازات ورفع الملفات وحفظ الفرص غير متاحة. التصفح والفلاتر وقراءة التفاصيل متاحة.

## التصور المقترح للحساب الحقيقي

ينشئ الباك إند ملفًا مرتبطًا بمعرف الحساب بعد التسجيل. في أول دخول يطلب تأكيد الاسم واختيار الكلية والتخصص والاهتمامات اللازمة للتخصيص؛ يمكن تعبئة الاسم مقدمًا إن أعاده مزود التسجيل. النبذة والمهارات والإنجازات والمرفقات اختيارية وتضاف لاحقًا. بعد إكمال التعريف الأولي يفتح الطالب الرئيسية، وفي الدخول اللاحق ينتقل إليها مباشرة. هذا المسار اقتراح للربط القادم وليس مصادقة أو استبيانًا منفذًا الآن.
