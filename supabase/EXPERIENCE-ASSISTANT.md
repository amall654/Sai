# مساعد كتابة تجربة الطالب — قيد الربط

أضيفت واجهة تسجيل صوتي بحد دقيقتين و10MB، مع معاينة التسجيل وحذفه. الصوت في ذاكرة الصفحة فقط ولا يُرفع إلا عندما يختار الطالب التحويل. النص الناتج اقتراح قابل للتحرير؛ لا يستبدل المسودة ولا ينشرها تلقائيًا.

**لم تُنشر وظيفة الخادم ولم يُختَر مزود الذكاء الاصطناعي بعد.** لا تعتبر هذه الميزة مكتملة أو جاهزة للاختبار الحقيقي للتحويل والصياغة. الاختبارات المحلية تستخدم استجابة محاكاة للنص المقترح.

## العقد المطلوب للخادم

- Supabase Edge Function باسم `experience-assistant`.
- التحقق من JWT والمستخدم المؤكد قبل المعالجة، وحدود طلبات لكل مستخدم وحجم/مدة الصوت، ومهلة للطلبات.
- الصياغة: JSON `{action:"rewrite",text:"..."}` بحد 6000 حرف.
- التحويل: multipart يحتوي `action=transcribe` وملف `audio`. التحقق من نوع الملف وحجمه على الخادم أيضًا.
- النجاح: JSON `{text:"..."}`. لا تُسجّل نصوص التجارب أو الصوت في السجلات.
- مفتاح المزود في Supabase Secrets فقط. تحديد CORS لرابط الموقع المحلي والعام، دون الاعتماد على CORS كوسيلة مصادقة.
- تعليمات الصياغة تحافظ على الوقائع وصوت الطالب ولا تختلق إنجازات، وتعامل النص كبيانات لا كتعليمات.
- قبل التفعيل: تحديد المزود والتكلفة وسياسة الاحتفاظ بالبيانات، وإظهار تنبيه مشاركة المحتوى مع المزود للطالب، ثم اختبار العربية والتسجيل الحقيقي وإلغاء الطلب والصلاحيات وحدود الاستخدام.

لا تُرفع هذه الواجهة كميزة مكتملة حتى إتمام الربط أعلاه. الكتابة والإرسال العاديان يظلان متاحين عند فشل المساعدة.
